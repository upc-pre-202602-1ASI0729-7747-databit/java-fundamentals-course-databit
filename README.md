# Fundamentos de Java para Principiantes

Curso introductorio de programación con Java en video para estudiantes de secundaria. En 8 lecciones cortas, cada estudiante aprende los fundamentos del lenguaje y de la Programación Orientada a Objetos (POO), y termina con su propio reproductor de música en la consola.

No hay nada que instalar: todo se hace desde el navegador.

- **Duración total**: ~60 minutos
- **Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
- **Prerrequisitos**: Ninguno
- **Herramientas necesarias**: Solo un navegador web (Chrome, Firefox, Safari o Edge)
- **Editor en línea**: [JDoodle](https://www.jdoodle.com/online-java-compiler), gratuito

**Plan del curso**: [course-plan.md](course-plan.md), con los videos y las prácticas de cada lección.

## Cómo usar este repositorio

1. Abre [course-plan.md](course-plan.md) y sigue las lecciones en orden.
2. En cada lección, mira el video y abre su enlace del editor en línea para practicar.
3. Si te atrasas o algo no funciona, compara tu código con `completed-examples/`.

## Configuración

No necesitas instalar nada ni crear una cuenta para practicar.

1. Abre el enlace de la práctica en [course-plan.md](course-plan.md). El código inicial ya viene cargado.
2. Si prefieres empezar desde cero, abre [JDoodle](https://www.jdoodle.com/online-java-compiler) y copia el contenido del archivo `Main.java` de `starter-files/`.
3. Pulsa **Execute** para ejecutar tu programa.
4. Si el programa pide datos, deja activada la opción **Interactive** y escribe tus respuestas en la sección **Output**.
