## Parte 2: Una variable es una caja con nombre (0:25 a 1:05)

**En pantalla**: Diapositiva con las tres cajas: edad, nombre y puntos.

**Narración**:
Una variable es como una caja con nombre. Aquí tenemos tres cajas: edad guarda el número 15, nombre guarda el texto Luna y puntos guarda 120.

Cada caja tiene un nombre que nos sirve para encontrarla, y guarda un dato que podemos usar después. Así, una variable guarda un dato para usarlo cuando lo necesitemos.

## Parte 3: Declarar una variable (1:05 a 1:50)

**En pantalla**: Diapositiva con `int edad = 15;` y las tres tarjetas: tipo, nombre y valor.

**Narración**:
Para crear una variable, la declaramos, y tiene tres partes. Mira esta línea: int edad igual a 15.

Primero, el tipo, int, que dice qué clase de dato guarda. Segundo, el nombre, edad, que es cómo la llamamos. Y tercero, el valor, 15, que es el dato que guarda. Y al final, el punto y coma.

## Parte 4: Tipos de datos básicos (1:50 a 2:50)

**En pantalla**: Diapositiva con las cuatro tarjetas de tipos: int, double, boolean y String.

**Narración**:
Java tiene distintos tipos de datos. int guarda números enteros, sin decimales, como la edad. double guarda números decimales, como la altura 1.65; en Java el decimal se escribe con punto.

boolean guarda verdadero o falso: solo dos valores, true o false. Y String guarda texto y va entre comillas dobles; fíjate que String se escribe con S mayúscula.

Elegir bien el tipo es decidir qué clase de caja necesitas.

**Narración**:

Ejecutamos y aparece 15. Las variables pueden cambiar de valor, ¡por eso se llaman variables!

## Parte 6: Operadores aritméticos (3:40 a 4:50)

**En pantalla**: Diapositiva con las cinco tarjetas de operadores: suma, resta, multiplicación, división y residuo.

**Narración**:
Para hacer cálculos usamos operadores. El signo más suma, el menos resta, el asterisco multiplica y la barra divide.

Ojo con la división: con números int el resultado no tiene decimales, así que 7 dividido entre 2 da 3, no 3.5.

Y por último, el signo de porcentaje, que se llama residuo: nos da lo que sobra de una división. Diez entre 3 es 3 y sobra 1, así que 10 porcentaje 3 da 1. Lo usaremos más adelante en el curso.
