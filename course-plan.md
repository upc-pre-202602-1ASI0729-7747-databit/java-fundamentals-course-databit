# Fundamentos de Java para Principiantes

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a los fundamentos de la programación con Java, incluyendo la Programación Orientada a Objetos (POO). Lección a lección, cada estudiante avanza hasta construir su propio reproductor de música en la consola. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos  
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación  
**Prerrequisitos**: Ninguno  
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari o Edge)  
**Editor en línea**: [JDoodle](https://www.jdoodle.com/online-java-compiler), gratuito

**📁 Repositorio de código fuente**: [https://github.com/upc-pre-202602-1ASI0729-7747-databit/java-fundamentals-course-stockia](https://github.com/upc-pre-202602-1ASI0729-7747-databit/java-fundamentals-course-stockia)

## Secuencia de Lecciones

### Lección 1: ¿Qué es Java y la programación? (5 minutos)

- **Descripción**: Descubre qué es programar, por qué Java es un buen lenguaje para empezar y escribe tu primer programa.
- **Enlace**: [Ver la lección](https://youtu.be/LD2NPrIsabo)
- **Conceptos clave**:
  - Programar es dar instrucciones en orden.
  - Java es un lenguaje para crear aplicaciones y juegos.
  - `System.out.println` muestra un mensaje en pantalla.
- **Práctica**: [Clic para programar](https://www.jdoodle.com/online-java-compiler) 👉 **¡No necesitas registrarte!**

---

### Lección 2: Variables, tipos de datos y operadores (10 minutos)

- **Descripción**: Aprende a guardar datos en variables y a hacer operaciones con ellos.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L2)
- **Conceptos clave**:
  - Una variable guarda un dato con un nombre.
  - Los tipos más usados son `int`, `double`, `boolean` y `String`.
  - Los operadores `+`, `-`, `*` y `/` hacen cálculos.
  - El operador `%` devuelve el residuo de una división.
- **Práctica**: [Clic para programar](PEGAR_JDOODLE_L2) 👉 **¡Inicio inmediato!**

---

### Lección 3: Estructuras de control (10 minutos)

- **Descripción**: Haz que tu programa tome decisiones con `if` y `else`, y que repita tareas con bucles.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L3)
- **Conceptos clave**:
  - `if` y `else` eligen qué hacer según una condición.
  - `for` repite una tarea un número de veces.
  - `while` repite una tarea mientras se cumpla una condición.
- **Práctica**: [Clic para programar](PEGAR_JDOODLE_L3) 👉 **¡No necesitas registrarte!**

---

### Lección 4: Métodos, entrada y salida (5 minutos)

- **Descripción**: Organiza tu código en métodos reutilizables y lee lo que escribe el usuario con `Scanner`.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L4)
- **Conceptos clave**:
  - Un método agrupa instrucciones que puedes reutilizar.
  - Los parámetros envían datos a un método.
  - `return` devuelve un resultado.
  - `Scanner` lee lo que el usuario escribe con el teclado.
- **Práctica**: [Clic para programar](PEGAR_JDOODLE_L4) 👉 **¡Inicio inmediato!**

---

### Lección 5: Clases, objetos y encapsulación (10 minutos)

- **Descripción**: Entra a la Programación Orientada a Objetos creando tu primera clase `Reproductor` con atributos, constructor y métodos.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L5)
- **Conceptos clave**:
  - Una clase es un molde y un objeto se crea a partir de ella con `new`.
  - El constructor prepara el objeto al crearlo.
  - `private` protege los atributos de una clase.
  - Los getters y setters leen y cambian esos atributos con reglas.
- **Práctica**: [Clic para programar](PEGAR_JDOODLE_L5) 👉 **¡No necesitas registrarte!**

---

### Lección 6: Arrays y cadenas (5 minutos)

- **Descripción**: Guarda listas de datos en arrays y trabaja con textos, integrándolos con tus objetos.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L6)
- **Conceptos clave**:
  - Un array guarda varios valores del mismo tipo.
  - Las posiciones de un array empiezan en 0.
  - `length` indica cuántos elementos tiene un array.
  - `String` ofrece métodos para trabajar con textos.
- **Práctica**: [Clic para programar](PEGAR_JDOODLE_L6) 👉 **¡Inicio inmediato!**

---

### Lección 7: Proyecto: un programa con POO (10 minutos)

- **Descripción**: Junta clases, encapsulación, arrays, `Scanner` y bucles para crear un reproductor de música que funciona en la consola.
- **Enlace**: [Ver la lección](https://youtu.be/Q9BxaGhTSLY)
- **Conceptos clave**:
  - Antes de escribir código se planifica: cada clase se ocupa de lo suyo.
  - `Reproductor` protege sus datos con `private` y solo los cambia con sus métodos.
  - El residuo `%` hace que la lista de canciones dé la vuelta sin usar un `if`.
  - `Scanner` lee la opción del usuario y `while` repite el menú hasta que elige salir.
  - Leer los errores y usar `println` ayuda a encontrar problemas.
- **Proyecto final**: [Crea tu reproductor](https://www.jdoodle.com/ga/rk2h-9mqr-dc2g) 👉 **¡Guarda y comparte!**

---

### Lección 8: Consejos y próximos pasos (5 minutos)

- **Descripción**: Conoce los errores comunes, las buenas prácticas y qué puedes aprender después.
- **Enlace**: [Ver la lección](PEGAR_YOUTUBE_L8)
- **Conceptos clave**:
  - Lee los mensajes de error: indican en qué línea está el problema.
  - Usa nombres claros y una sangría ordenada.
  - Prueba tu programa después de cada cambio.
  - Sigue aprendiendo con la [documentación oficial de Java](https://dev.java/learn/).
- **Comparte tu trabajo**: [Envía tu creación](PEGAR_FORM_CREACION)
